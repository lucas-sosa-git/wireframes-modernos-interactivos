# Plan Codice Template

Use this template when the user asks for a Plan Codice.

# Plan Codice - [Nombre de la funcionalidad]

## Modelo recomendado
Usar GPT-5.4 con inteligencia media y velocidad normal.

## Objetivo funcional
Describe exactly what must work.

## Objetivo UI/UX
Describe how the experience should feel and look.

## Archivos a revisar
List only the direct target files and dependencies.

## Archivos que no debe tocar
List protected files and folders.

## Comportamiento actual a verificar
Explain what Codex must inspect before changing code.

## Flujo UX propuesto
Describe the user journey and visible states.

## Cambios por archivo
Break down the changes by file.

## Criterios de aceptación
List concrete pass/fail outcomes.

## Validaciones manuales
List browser/manual checks.

## Validaciones técnicas
List commands and code checks.
